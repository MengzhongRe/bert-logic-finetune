## 📋 项目概述
### 核心目标
1. 量化模型在4类逻辑句式、6大垂直领域的情感分类准确率；
2. 通过3轮重复测试，验证模型能力边界与短板稳定性；
3. 输出精准、可落地的微调方案，实现短板突破；
4. 形成完整工程链路（数据构建→基准测试→交叉分析→微调指导），适配面试展示。

### 测试环境
- 模型：`uer/roberta-base-finetuned-dianping-chinese`（未微调）
- 数据集：3轮×960条结构化数据（4句式×6领域×等样本，去模板化+硬编码标注）
- 评估维度：逻辑句式、垂直领域、句式×领域交叉、全局P/R/F1
- 硬件：NVIDIA GeForce RTX 5070 Ti（cuda:0）

## 🎯 三次测试交叉分析结论
### ✅ 模型固有优势（无需优化）
1. **简单句全领域统治力**：三次测试准确率持续攀升至95.42%，全领域均≥90%，成为模型“基础盘”，无优化空间；
2. **双重否定非日常社交领域**：美食餐饮（91.67%）、生活服务（90.83%）、影视娱乐（90.83%）表现优异，仅需保持；
3. **负向情感识别**：F1稳定0.89，准召均衡（0.86/0.93），无漏判/误判问题；
4. **高结构化领域适配**：影视娱乐、购物消费等场景化/结构化文本理解能力扎实，波动为数据差异导致。

### ⚠️ 顽固短板（微调核心靶点）
1. **语义反转理解不足**：反讽句式全领域表现＜80%，依赖语境的反讽（如美食/服务场景）识别能力最弱；
2. **口语化逻辑捕捉弱**：日常社交领域+复杂句式（双重否定/转折关系）表现拉胯，无结构化语境支撑时模型失效；
3. **正向情感漏判**：Positive类召回率仅80%-82%，存在“宁判负不判正”倾向；
4. **交叉场景适配差**：低优句式（反讽/双重否定）+低优领域（日常社交/生活服务）的组合准确率最低。

### 📌 关键发现（数据层面）
1. **数据质量决定表现**：日常社交/出行旅游领域因数据“口语化/场景细节丰富”，准确率提升6%+，证明微调数据需强化场景细节；
2. **模型能力边界固化**：三次测试核心指标无明显波动，优势/短板高度一致，微调需聚焦“单点突破”，而非泛化优化；
3. **反讽为固有缺陷**：反讽句式依赖深层语义理解，模型无结构化特征可捕捉，需通过高质量数据+特征增强突破。

## 🚀 最终精准微调方案（落地性拉满）
### 🔴 微调优先级（聚焦靶点，拒绝泛化）
| 优先级 | 目标场景                          | 微调前准确率 | 微调目标 | 提升幅度 |
|--------|-----------------------------------|--------------|----------|----------|
| S级    | 双重否定+日常社交                  | 67.50%       | ≥80.00%  | ≥12.5%   |
| S级    | 反讽+美食餐饮/生活服务/出行旅游    | 70%-75%      | ≥82%-85% | ≥10%-15% |
| A级    | 转折关系+生活服务/日常社交/购物消费 | 80%-82.5%    | ≥88.00%  | ≥5.5%-8%  |
| A级    | Positive类召回率                  | 80%-82%      | ≥85.00%  | ≥5.0%    |
| B级    | 全局准确率                        | 87.00%       | ≥90.00%  | ≥3.0%    |

### 1. 数据层优化（核心：高质量+场景化）
#### （1）S级短板数据扩充（精准突破）
- **双重否定+日常社交**：新增150条样本
  ✅ 纯口语化表达（亲友闲聊、日常琐事）；
  ✅ 多结构（无…不…/不是没有…/不可能不…）；
  ✅ 正负情感各75条，含具体场景细节（时间/动作/关系）。
- **反讽+三大领域**：每类新增120条样本
  ✅ 贴合领域场景（美食：吐槽餐厅；服务：吐槽服务；出行：吐槽旅行）；
  ✅ 多结构反讽（避免“你可真XX”）；
  ✅ 负面反讽占80%，正面反讽聚焦亲友亲昵吐槽。

#### （2）数据集融合与划分
- 训练集：三次测试高准确率样本（≥85%，≈1600条）+ 新增短板样本（≈650条）= 2250条；
- 验证集：从训练集中按1:5拆分（≈450条），确保“句式+领域”分布一致；
- 测试集：单独保留第三次测试960条数据（未参与训练），用于最终验证。

### 2. 模型层优化（分层微调+特征增强）
#### （1）基础微调（全量训练集·1轮）
- 学习率：3e-5；Batch Size：16；优化器：AdamW（权重衰减=0.01）；
- 损失函数：交叉熵损失+F1损失（提升Positive召回率）；
- 监控指标：核心短板准确率、验证集准确率；
- 停止条件：验证集准确率≥90% 或 短板提升≥10%。

#### （2）定向微调（S/A级短板·2轮）
- 学习率：1e-5；Batch Size：8；
- 微调层：仅训练最后2层Transformer+分类层；
- 损失函数：焦点损失（Focal Loss，gamma=2，聚焦难分样本）；
- 停止条件：核心短板达标 或 验证集准确率不再提升。

#### （3）特征增强（针对性突破）
- 句式特征嵌入：将4类句式编码为4维特征，拼接至输入embedding；
- 领域特征嵌入：将6大领域编码为6维特征，与句式特征拼接；
- 冻结底层参数：仅训练顶层+分类层+特征嵌入层，避免优势退化。

### 3. 评估层优化（分层验证+量化效果）
#### 核心监控指标（量化目标）
| 指标类型       | 具体目标                          |
|----------------|-----------------------------------|
| 短板突破       | S级场景≥80%，A级场景≥88%          |
| 全局性能       | 准确率≥90%，Positive召回率≥85%    |
| 优势保持       | 简单句/双重否定非日常社交≥90%（波动≤2%） |
| 泛化能力       | 独立测试集（第三次960条）准确率≥90% |
